# Steve Jobs Tribute Page

A responsive single-page tribute website dedicated to Steve Jobs, co-founder of Apple and one of the most influential figures in modern technology.

## Project Overview

This project was created as part of a frontend development assignment to demonstrate fundamental HTML5 and CSS3 skills.

The website presents a visual journey through Steve Jobs' life, career, major products and lasting influence on technology and design.

## Technologies Used

- HTML5
- CSS3

No JavaScript, CSS frameworks or external UI libraries were used.

## Features

- Semantic HTML5 structure
- Responsive design
- Mobile and desktop layouts
- Steve Jobs biography
- Career timeline
- Major achievements
- Quote section
- CSS hover effects
- Responsive typography
- Accessible image alt text
- Smooth scrolling navigation

## Page Sections

### 1. Hero

Introduces Steve Jobs with a large typography-based hero section and portrait.

### 2. About

Provides a brief overview of Steve Jobs' background, career and philosophy.

### 3. Timeline

Highlights important moments from his life and career:

- 1955 — Born in San Francisco
- 1976 — Apple founded
- 1984 — Macintosh introduced
- 1997 — Returned to Apple
- 2001 — iPod introduced
- 2007 — iPhone introduced
- 2011 — Passed away

### 4. Achievements

Highlights products and ideas associated with Steve Jobs, including:

- Macintosh
- iMac
- iPod
- iPhone
- iPad
- Product design philosophy

### 5. Legacy

Discusses the lasting influence of Steve Jobs on technology, design and entrepreneurship.

## Design Approach

The design uses a minimalist visual language inspired by the simplicity associated with Apple's product design.

The main visual characteristics include:

- Black and white color palette
- Large typography
- Generous whitespace
- Minimal borders
- Grayscale imagery
- Editorial-style layout
- Subtle hover animations

The design intentionally avoids copying Apple's website and instead uses minimalism as the primary visual concept.

## Responsive Design

The website has responsive breakpoints for:

- Desktop
- Tablet
- Mobile
- Small mobile devices

CSS Grid is used for the content and achievement cards, while media queries adapt the layout for smaller screens.

## Accessibility

Basic accessibility practices were included:

- Semantic HTML elements
- Descriptive image `alt` text
- Proper heading hierarchy
- Readable color contrast
- Responsive typography
